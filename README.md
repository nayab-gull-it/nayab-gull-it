<summary><b>&gt; FraudScope — Privacy-First Fraud Detection Tool</b></summary>
<br/>

A live, full-stack fraud/anomaly detection tool for financial ledgers. All detection math (outlier detection, duplicate/round-number/threshold-skirting checks, timing anomalies, vendor concentration) runs locally on the server with pandas/numpy — an LLM only ever receives anonymized, aggregated statistics, never raw transaction data.
